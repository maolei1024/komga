# Gorse 连读

“二次开发”菜单集中提供 Gorse 连读、Gorse 推荐设置、元数据增强和去重管理。后三项仅管理员可见；连读需要在线阅读权限。原有管理页面的 URL 保持兼容。

## 使用

- 从“二次开发 → Gorse 连读”或首页 Gorse 推荐区选择作品。
- 系列实际只有一集时直接开读；多集则在弹层中选集。
- 沿用现有阅读设置。到达最后一页末端后，再按一次 `↓` 或点击书末按钮，接续同系列下一集；系列结束后显示推荐。
- 推荐面板支持方向键选书、`Enter` 打开、`Esc` 返回。可继续在面板内选集。
- 关闭阅读器直接返回推荐页。重新进入菜单只显示推荐，不增加跨次恢复入口。

## 实现边界

`/custom/gorse` 为推荐入口；图片阅读路由使用 `mode=gorse` 启用连读。普通阅读及 EPUB 阅读器保持原流程。连读复用原有 REST API，不新增 Gorse 反馈写入。

推荐快照最多 100 个系列，每批显示 20 个；同次连读按系列去重，耗尽后自动刷新一次。候选和已打开系列仅保存在内存中，重新进入推荐页或切换账户时重新开始。

书籍页码仍由 Komga 保存。切换前等待进度写入；保存失败时保留当前书并提供重试。无痕阅读不写进度。

## 验证

使用 Node 20，在此目录执行 `npm run test:unit -- --runInBand`、`npm run typecheck` 和 `npm run build`。

浏览器验收包括首页与新页面单集直读、多集选集后依序接续、书末键盘和触屏选推荐、长图片未到底时不切换、双页和短书、弹层关闭与焦点、推荐加载失败、进度失败重试、普通阅读回归，以及不同角色的菜单与旧链接。
