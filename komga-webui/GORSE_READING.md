# Gorse 连读

“二次开发”菜单集中提供 Gorse 连读、Gorse 推荐设置、元数据增强和去重管理。后三项仅管理员可见；连读需要在线阅读权限。原有管理页面的 URL 保持兼容。

## 使用

- 从“二次开发 → Gorse 连读”或首页 Gorse 推荐区选择作品。
- 系列实际只有一集时直接开读；多集则在弹层中选集。
- 沿用现有阅读设置。到达最后一页末端后，再按一次 `↓` 或点击书末按钮，接续同系列下一集；系列结束后显示推荐。
- 推荐面板支持方向键选书、`Enter` 打开、`Esc` 返回。可继续在面板内选集。
- 关闭阅读器直接返回推荐页。重新进入菜单只显示推荐，不增加跨次恢复入口。
- 推荐卡片以单行显示内容标签数和实际总页数；技术标签不计入统计，页数未知时显示 `—`。选集时显示该集的统计并保留集号。
- 小于 960px 的屏幕使用全屏选书面板，顶部关闭按钮保持可见，列表独立滚动。
- 系列最后一集读到实际末端后，桌面顶部、移动端底部显示作品摘要和“喜欢／不喜欢”。展开“推荐特征”可查看 Gorse 实际保存的作者、内容标签、分桶、题材、社团和角色；卡片标签数与 Gorse 内容标签数分别显示。
- 点击反馈会先保存最后一页进度，再提交整个系列的偏好。反馈后留在当前界面；选书、选集期间仍针对刚读完的系列。无痕模式只展示信息，不显示反馈按钮。
- 特征信息或偏好读取失败可分别重试；提交失败会重试原选择。`Esc` 优先收起特征详情，再关闭推荐面板。

## 实现边界

`/custom/gorse` 为推荐入口；图片阅读路由使用 `mode=gorse` 启用连读。普通阅读及 EPUB 阅读器保持原流程。选书、进度与反馈提交复用原有 REST API，不增加新的 Gorse 反馈类型。

推荐快照最多 100 个系列，每批显示 20 个；同次连读按系列去重，耗尽后自动刷新一次。候选和已打开系列仅保存在内存中，重新进入推荐页或切换账户时重新开始。

书籍页码仍由 Komga 保存。切换前等待进度写入；保存失败时保留当前书并提供重试。无痕阅读不写进度。

已登录用户在详情页设置喜欢或不感兴趣时，当前整个系列的未删除集会完成阅读，同时确认 Gorse 已保存偏好和已读反馈。取消偏好保留已读记录；历史偏好不批量补处理，后来新增的集不自动完成。旧匿名反馈接口保持原行为。失败时可重试原目标，服务端补偿本次未完成的反馈修改。

推荐接口的系列对象附带可选 `tagCount` 和 `pagesCount`，页数按批次聚合，不为每张卡片额外请求书籍列表。

`GET /api/v1/gorse/preference/series/{seriesId}/context` 提供书末特征信息，校验登录、书库权限及内容限制。`featuresStatus` 为 `AVAILABLE`、`MISSING` 或 `UNAVAILABLE`；后两者保留本地统计，不推算 Gorse 标签或分桶，也不触发同步。此展示不调整训练或按特征拆分反馈，不预测单次反馈对模型的影响。

实时上报和批量同步的 `read` 时间均从服务器本地时区转换为 UTC。旧版本曾将本地时间直接标为 UTC；已有错误记录不会自动修复，需在修复版本上线后由管理员使用现有反馈同步重新投递。该同步只写入已读反馈，保留喜欢和不感兴趣反馈。

## 验证

使用 Node 20，在此目录执行 `npm run test:unit -- --runInBand`、`npm run typecheck` 和 `npm run build`。

浏览器验收包括首页与新页面单集直读、多集选集后依序接续、书末键盘和触屏选推荐、长图片未到底时不切换、双页和短书、弹层关闭与焦点、推荐加载失败、进度失败重试、普通阅读回归，以及不同角色的菜单与旧链接。

后端反馈与进度联动由 `GorseReadingProgressIntegrationTest` 覆盖。可启动只监听本机的独立 Gorse，使用独立数据目录、API key `local-validation-only`，设置 `KOMGA_TEST_GORSE_URL=http://127.0.0.1:<port>` 后运行 `GorseReadingPreferenceLiveTest`，验证真实反馈存储；该测试默认跳过，不连接生产实例。
